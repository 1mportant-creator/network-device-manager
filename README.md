# network-device-manager
**项目名称：网络设备管理器
#
# 功能：
# 1. 查看所有设备
# 2. 添加设备
# 3. 删除设备
# 4. 修改配置
# 5. 导入Cisco配置
# 6. 退出
#
# 技术点：
# - 数据结构：列表、字典
# - 控制流：if条件判断、for循环、while True循环
# - 字符串处理：strip()、split()、startswith()
# - 函数封装：def定义函数、参数传递、返回值
# - 文件操作：with open() as f、CSV读写
# - 异常处理：try/except
# - 内置函数：len()、enumerate()、replace()
#
# 使用场景：
# - 小型网络运维团队日常设备台账管理
# - 批量导入交换机/路由器配置，自动生成设备清单
#- 作为网络自动化运维系统的基础模块
